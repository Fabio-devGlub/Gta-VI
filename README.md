# 🎮 GTA VI - Projeto Frontend Interativo

Este projeto foi desenvolvido durante a **Semana do Programador Contratado**, com foco em criar uma página moderna e interativa inspirada no universo de GTA VI.pagina Clone  
Ao longo do desenvolvimento, aprendi conceitos importantes de **responsividade**, uso de **bibliotecas de animação** e integração de **vídeos** na web.

## 🚀 Tecnologias e ferramentas
- **HTML5** → Estrutura da página
- **CSS3** → Estilização avançada e responsividade
- **JavaScript (ES6+)** → Interatividade
- **GSAP** → Animações fluidas e dinâmicas
- **ScrollTrigger (GSAP plugin)** → Efeitos ativados pelo scroll
- **Vídeo embutido** → Experiência multimídia

## 📂 Estrutura do projeto
- `index.html` → Página principal
- `style.css` → Estilos visuais e responsivos
- `script.js` → Funções, animações e interações
- `assets/` → Imagens e vídeos

## ✨ Funcionalidades
- Layout temático inspirado em GTA VI
- Página **totalmente responsiva** para diferentes dispositivos
- Animações com **GSAP** e **ScrollTrigger**
- Integração de **vídeos** para enriquecer a experiência
- Elementos visuais modernos com CSS (gradientes, transições, efeitos hover)
